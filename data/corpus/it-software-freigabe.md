# Software-Freigabeliste und Antragsprozess

## 1. Grundsatz

Auf Firmengeräten darf nur Software aus dem Unternehmens-Softwareportal installiert werden. Lokale Administratorrechte werden nur für Entwicklerarbeitsplätze und nur befristet vergeben.

## 2. Freigegebene Standardsoftware

| Software | Kategorie | Freigabe für |
|---|---|---|
| Microsoft 365 (Word, Excel, Outlook, Teams) | Office | alle |
| Visual Studio Code | Entwicklung | alle |
| Python 3.12 | Entwicklung | Entwicklung, Data, IT |
| Docker Desktop | Entwicklung | nur Entwicklung (Lizenzpflicht beachtet) |
| Git for Windows | Entwicklung | Entwicklung, Data, IT |
| 7-Zip | Werkzeuge | alle |
| Adobe Acrobat Reader | Werkzeuge | alle |
| Siemens NX | CAD | Konstruktion |
| Siemens Sinumerik Operate (PC-Version) | Maschinen | Service, Anwendungstechnik |
| Bitwarden | Sicherheit | alle |
| Cisco Webex | Kommunikation | Vertrieb (für Kundentermine) |

## 3. Nicht zugelassene Software

Ausdrücklich nicht zugelassen sind: private Cloud-Speicher (Dropbox, private OneDrive/Google-Drive-Konten), WhatsApp Desktop, TeamViewer (außer durch die IT), Browser-Erweiterungen ohne Freigabe sowie sämtliche Software aus nicht vertrauenswürdigen Quellen.

## 4. Antrag auf neue Software

1. Antrag in ServiceNow (Kategorie „Software-Antrag") mit Begründung und Anzahl der Nutzer.
2. Prüfung durch IT-Security (Sicherheit, Datenschutz) und Einkauf (Lizenz).
3. Entscheidung innerhalb von **10 Arbeitstagen**.
4. Bei Freigabe: Aufnahme ins Softwareportal und Information des Antragstellers.

Open-Source-Software wird bevorzugt geprüft; Software mit Copyleft-Lizenzen (z. B. GPL) darf nicht in Produkte eingebettet werden, ohne dass die Rechtsabteilung zugestimmt hat.

## 5. Lizenz-Compliance

Die IT führt halbjährlich eine Lizenzinventur durch. Nicht lizenzierte Software wird ohne Vorankündigung deinstalliert.

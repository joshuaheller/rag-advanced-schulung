# Betriebshandbuch CNC-Fräsmaschine AX-100 (Auszug)

Die AX-100 wird seit 2023 nicht mehr gefertigt; das Handbuch gilt weiterhin für Bestandsmaschinen im Feld.

## 1. Bestimmungsgemäße Verwendung

Die AX-100 ist ein kompaktes 3-Achs-Vertikalbearbeitungszentrum für Aluminium und Kunststoffe sowie für leichte Stahlbearbeitung.

## 2. Technische Daten

| Merkmal | AX-100 |
|---|---|
| Verfahrweg X / Y / Z | 600 / 400 / 400 mm |
| Tischgröße | 700 × 400 mm |
| Maximale Tischbelastung | 350 kg |
| Spindeldrehzahl | max. 10.000 U/min |
| Spindelleistung (S1) | 11 kW |
| Werkzeugaufnahme | SK 40 |
| Werkzeugwechsler | 20 Plätze |
| Eilgang X / Y / Z | 30 / 30 / 24 m/min |
| Steuerung | Siemens Sinumerik 808D |
| Maschinengewicht | ca. 3.100 kg |
| Anschlussleistung | 18 kVA, 400 V / 50 Hz |

## 3. Wartungsintervalle

| Wartungsarbeit | Intervall |
|---|---|
| Späne entfernen, Kühlmittelstand prüfen | täglich |
| Spindelöl wechseln | alle 600 Betriebsstunden |
| Führungen abschmieren | alle 1.200 Betriebsstunden |
| Kühlmittel komplett wechseln | alle 6 Monate |
| Hydraulikölwechsel | jährlich |
| Sicherheitsprüfung | jährlich durch Aurelia-Service |

## 4. Ersatzteile

Ersatzteilversorgung ist bis 2033 zugesichert. Bestellung über das Serviceportal mit Maschinennummer.
